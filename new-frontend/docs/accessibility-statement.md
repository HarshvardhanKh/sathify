# Accessibility Conformance Statement - SaathiFy

SaathiFy is committed to delivering a web application that conforms strictly to the **Web Content Accessibility Guidelines (WCAG) 2.2 Level AA** standards.

---

## 1. Conformance Status
Our team regularly tests layouts against WCAG guidelines, screen readers, keyboard-only paths, and high contrast conditions to guarantee compatibility.

- **Color Contrast**: Active primary content meets or exceeds the **7:1 AAA ratio** (for default navy `#022F84` and dark backgrounds). Accent highlights meet the **4.5:1 AA ratio** (for warm ambers and sky blues).
- **Keyboard Traps**: Every interactive modal, setting selector, and outlines drawer allows full keyboard navigation with clear focus indicator rings.
- **Forced Colors Mode**: Text and status indicators remain visible under Windows High Contrast settings by using border outlines and semantic SVG icons alongside raw colors.

---

## 2. Accessibility Hotkeys
Global hotkeys are provided to navigate core features quickly:

- `Alt + D`: Main Dashboard Navigation focus
- `Alt + L`: Jump to Live Studio Caption stream
- `Alt + K`: Keyboard help reference overlay
- `Alt + C`: Toggle complexity levels per paragraph
